# Deep Learning Lab (BCS701)

Deep Learning lab programs for VTU 7th semester, CSE (AI & ML).

All 8 programs are in the notebook, with outputs shown under each cell.

| # | Program | Dataset |
|---|---------|---------|
| 1 | Word embeddings using Word2Vec | Sample corpus |
| 2 | Deep neural network classification | Iris |
| 3 | CNN image classification | MNIST |
| 4 | Autoencoder for image compression | MNIST |
| 5 | Text document classification | IMDB |
| 6 | Time series forecasting using LSTM | Synthetic data |
| 7 | Image classification using a pre-trained model (MobileNetV2) | CIFAR-10 |
| 8 | Review sentiment classification | Sample reviews |

## How to run
1. Open the notebook in Google Colab.
2. Go to Runtime, then Change runtime type, and choose GPU.
3. Go to Runtime, then Run all.

## Libraries used
TensorFlow, Keras, scikit-learn, NumPy, Matplotlib, Gensim
